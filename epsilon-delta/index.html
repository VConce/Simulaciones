1. Elige qué investigar

Cómo escribir una función

Usa * para multiplicar, / para dividir y ^ para potencias. Ejemplos: sin(x)/x, exp(-x^2), if(x<0,-1,1).

Admite sin, cos, tan, asin, acos, atan, sqrt, abs, exp, ln, log (natural), log10, floor, ceil, sign, min, max, pow; constantes pi y e. Ángulos en radianes. Es una expresión real, no código.

Qué demuestra (y qué no) este laboratorio

Encontrar un punto con 0 < |x − a| < δ y |f(x) − L| ≥ ε descarta ese δ. Que una muestra no encuentre ninguno no demuestra nada sobre todos los reales.

Un límite requiere una respuesta para cada ε > 0. En los ejemplos con cota matemática se explica la estimación utilizada. Para Thomae se comprueban los denominadores capaces de salir de la banda; para Dirichlet se utiliza la densidad de racionales e irracionales, no un test de decimales.

La condición se considera sobre el dominio de f, y a debe ser un punto de acumulación del dominio por el lado elegido. Las operaciones y distancias se calculan con precisión finita. Cerca de singularidades el gráfico puede omitir detalles.
