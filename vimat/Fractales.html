Fractales por iteración compleja

Explora mapas de escape del tipo zn+1=f(zn,c). Usa la rueda para hacer zoom y arrastra para desplazarte. Las iteraciones aumentan automáticamente al ampliar para conservar el detalle.

Modelo

Parámetros complejos

Introduce parte real e imaginaria. En modo Mandelbrot, c se toma del plano y estos valores actúan como desplazamiento. En modo Julia, c queda fijo y el plano representa z₀.
Cómo interpretar estos controles

Si el plano representa c, cada píxel usa c=p+c₀ y el mismo z₀ inicial. Si el plano representa z₀, cada píxel usa z₀=p+z₀,base y el mismo c. Así aparecen los comportamientos tipo Mandelbrot y tipo Julia.

Iteración y calidad

Uso

Zoom rueda del ratón sobre la zona que quieres ampliar.

Mover pulsa y arrastra el plano.

Órbita haz clic en un punto para ver sus primeras iteraciones.

Zoom adaptativo al ampliar se añaden iteraciones automáticamente, hasta un máximo de 50 000.

Consejo: funciones como exp, tan o grados grandes pueden escapar muy rápido. Baja el radio de escape o cambia el zoom para ver estructura.
