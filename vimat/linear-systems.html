Lectura de las ecuaciones

La intersección queda fuera de la vista actual.

La clasificación y las fracciones se calculan exactamente para los decimales introducidos. La representación gráfica y las coordenadas aproximadas usan aritmética de máquina.

Un punto, una recta, el plano o ningún punto

Dos rectas no paralelas tienen un único punto común. Las paralelas distintas no comparten ninguno y las coincidentes comparten todos sus puntos. Si ambos coeficientes de una ecuación son cero, ya no representa una recta: 0 = 0 no impone restricciones, mientras que 0 = c con c ≠ 0 es imposible.

El determinante no basta cuando vale cero

Si Δ ≠ 0 hay una solución única. Si Δ = 0, hay que comprobar también la compatibilidad de los términos independientes y las ecuaciones degeneradas; no se divide por ningún coeficiente que pueda ser cero.
