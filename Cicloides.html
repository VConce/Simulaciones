θ(t) = ωt
C(t) = (x₀ + Rθ(t), R)
P(t) = (x₀ + Rθ(t) + ρ cos(α − θ(t)), R + ρ sen(α − θ(t)))
ρ = R y α = −90° dan la cicloide ordinaria.

ρ < R produce una cicloide acortada; ρ > R, una alargada. La rueda cumple s = Rθ.
