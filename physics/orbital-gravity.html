Tipo de trayectoria
Modelo: el satélite cumple a = -GM r/r³ en modo central, o la suma a = -ΣGMi ri/ri³ si hay varias masas fijas. Para una masa central: vc = √(GM/r), ve = √(2GM/r), ε = v²/2 - GM/r. Si ε < 0 la órbita es ligada; si ε = 0 es parabólica; si ε > 0 es hiperbólica.
