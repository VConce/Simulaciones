# Espaguetizacion

Simulacion de fuerzas de marea con Einstein arrastrable, presets astronomicos y controles de masa/radio.

## Archivos
- `espaguetizacion.html`: version editable.
- `espaguetizacion_autocontenida.html`: version autocontenida.
- `assets/`: recursos locales.
- `versiones/`: historico desde `1.0`.
