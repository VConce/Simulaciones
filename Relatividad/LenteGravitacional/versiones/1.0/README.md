# LenteGravitacional

Simulacion de lente gravitacional con objetos arrastrables, agujero negro central, masa ajustable y observador Tierra.

## Archivos
- `lente_gravitacional.html`: version editable.
- `lente_gravitacional_autocontenida.html`: version autocontenida.
- `assets/`: recursos locales.
- `versiones/`: historico desde `1.0`.
